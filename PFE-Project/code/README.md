# Chatbot Orientation Bachelier

## Installation
1. Importer le script SQL dans votre base `chatbot_bachelier`.
2. Lancer le projet dans XAMPP/WAMP.
3. Naviguer vers `/auth/register.html` pour créer un compte.
4. Accéder à `/chat/dashboard` pour poser des questions.

## API OpenAI
Le fichier `chat_handler.php` contient une réponse simulée.
Remplacez-la par l'appel à l'API lorsque vous avez une clé.
